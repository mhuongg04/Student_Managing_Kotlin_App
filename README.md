# Student Managin Kotlin App
This is a Kotlin application for teachers to manage their students
It includes some features:
1. Add new students
2. Edit student's information
3. Delete students
4. Make phone calls, send emails to students

How to run the app:
1. Install Android Studio and neccessary tools
2. Sync the project with Gradle files
3. Run the app
